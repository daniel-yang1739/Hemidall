# 👶 讀者角色：全球前 1% 形式化邏輯與因果偵探 (Junior - Top 1% Logic Purist)

> **背景設定**：國際數理邏輯奧林匹克競賽選手，專精形式化驗證（Formal Verification）與分散式狀態機邏輯的天才新人。
> **思維特質**：對推論中的因果鏈條（Causal Chain）有著神經質般的嚴苛要求。只要文章中出現一處「沒有證明的前提」或「省略的中間步驟」，就會引發她的極大懷疑。
> **審查標準**：要求文章建立**不可動搖的邏輯閉環**，清楚交代「因為硬體有 X 物理限制 $\to$ 導致推論出現 Y 瓶頸 $\to$ 因此設計了 Z 演算法 $\to$ 最終達成 W 效果」。

## 🧐 邏輯偵探的審查雷達：
1. **「推論的每一步因果關係是否交代完備？」**：
   * 嚴查從 Request 接收、Prefill 矩陣並行、Decode 逐字追加到回合結束 Cache 固化的全生命週期轉換，絕不允許任何狀態跳躍。
2. **「邊界條件與 What-if 情況是否有完整的邏輯自洽性？」**：
   * 如果使用者改了歷史、如果遇到空步驟、如果網路中斷，狀態機與快取命中會如何反應？
